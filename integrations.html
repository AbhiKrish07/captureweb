Ecosystem & Protocol

Your context. Beyond Capture.

Your information shouldn't be locked inside one application. Capture uses the Model Context Protocol (MCP) to make permitted Space context safely accessible to your favorite AI clients.

01 · Clients

Supported AI Clients

Connect your desktop tools directly into Capture's context layer.

Claude Desktop

Anthropic Desktop App
Available

Read and search permitted Spaces directly from Claude conversations using local stdio MCP transport.

"capture": { "command": "capture", "args": ["mcp", "--serve"] }
Configuration: claude_desktop_config.json

Cursor IDE

AI Code Editor
Available

Expose project documentation, PRDs, and architecture specs to Cursor Composer without bloating your repository.

Type: command | Command: capture mcp
Settings > Features > MCP Servers

ChatGPT

OpenAI Assistant
Beta

Query permitted Space indexes via secure local relay webhooks and custom GPT tool endpoints.

Status: In private beta testing. Available for cohort users.

Custom MCP Agents

Python / Node SDK
