Ecosystem & MCP

Your context. Beyond Capture.

Your information should be accessible from the tools you already work with. Capture uses the Model Context Protocol (MCP) to make permitted Space information safely accessible without data fragmentation.

AI Clients

Connect external AI applications directly to your Capture context layer.

Claude Desktop

Anthropic AI Client
Available

Read and search permitted Spaces directly from Claude conversations using local stdio MCP transport.

"capture": { "command": "capture", "args": ["mcp", "--serve"] }
Setup: Add block to ~/Library/Application Support/Claude/claude_desktop_config.json

Cursor IDE

AI Code Editor
Available

Expose project documentation, PRDs, and architecture specs to Cursor Composer without bloating your code repository.

Type: command | Command: capture mcp
Setup: Enable in Cursor Settings > Features > MCP Servers

ChatGPT

OpenAI Assistant
Beta

Query permitted Space indexes via secure local relay webhooks and custom GPT tool endpoints.

Status: In private beta testing. Invitation granted upon beta enrollment.

Custom Agents & Python SDK

Infrastructure & Protocol

Transparent protocols ensuring zero lock-in.

Model Context Protocol (MCP)

Standard Core

Capture is natively designed around the open MCP specification, treating Spaces as first-class context resources.

Local REST API

Beta

Local-only HTTP daemon running on localhost with Bearer token authentication for custom shell scripts and Alfred / Raycast extensions.

Cloud App Connectors

Planned

Future connectors for Linear, GitHub Issues, and Google Drive will be released based on beta participant feedback.
