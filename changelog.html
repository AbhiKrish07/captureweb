Private Beta Release

Capture v0.1

Nov 2026

Initial private beta release for macOS. Establishes the foundational context workspace, desktop capture pipelines, and MCP server bridges.

Feature
Native Quick Capture: System-wide ⌥ Space floating capture bar on macOS for instant notes, clipboard clips, and file drops.
Feature
Personal Inbox: Frictionless single-stream holding area for unstructured context before routing into dedicated project Spaces.
Feature
Structured Spaces: Dedicated project environments supporting documents, PDFs, screenshots, URLs, and relationships.
Feature
Agent-powered Organization: Autonomous clustering suggestions, cross-document correlation, and contradiction detection.
Feature
Semantic Search: Local vector indexing and lexical keyword search across all captured artifacts with millisecond retrieval.
Integration
Initial MCP Server: Local JSON-RPC stdio daemon allowing Claude Desktop and Cursor to query permitted Space context directly.
