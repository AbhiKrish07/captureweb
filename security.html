Security & Architecture

Security by Architecture

How Capture protects personal information, isolates project Spaces, and enforces strict boundary control over AI agents.

1. Sandboxed Context Boundaries

Traditional AI tools pool user data into single conversational contexts. In Capture, context boundaries are strictly compartmentalized per Space. Documents, vector indexes, and chat sessions in one Space have zero cross-talk with unpermitted Spaces. External agents querying via MCP can only access the exact Space you have authorized.

2. Local-First Processing & Hardened Runtime

The macOS desktop application executes with hardened runtime entitlements under Apple's notarization framework:

  • Local SQLite & Vector Database: Raw captures and spatial relationships persist locally on your file system under application support directories.
  • Local OCR & Text Extraction: Screenshot text recognition is performed directly using macOS native Vision frameworks before any network queries are initiated.
  • Local MCP Transport: The Model Context Protocol daemon communicates over standard local input/output (stdio) sockets, eliminating open internet ports on your device.

3. Cryptographic Transmission & Authentication

All synchronization with cloud infrastructure occurs over TLS 1.3 with forward secrecy. Authentication utilizes passwordless, cryptographically signed magic links and hardware-backed biometric authentication (Touch ID) for desktop session locking.

4. AI Provider Agreements & Zero Training

All cloud-assisted agent reasoning is fulfilled under commercial enterprise API terms with frontier AI labs. These agreements legally guarantee that your project documents, notes, and generated summaries are never utilized to train or fine-tune public foundation models.
